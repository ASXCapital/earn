# RewardPool Contract

Staking pool contract for CoreDAO.  
See `contracts/RewardPool.sol` for details.

## Requirements
- Solidity 0.8.19
- [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts)

## Usage

Install dependencies:
```
npm install
```

Deploy pools (BSC mainnet):
```
# fill deploy-pools.json first
npm run deploy:pools
```
